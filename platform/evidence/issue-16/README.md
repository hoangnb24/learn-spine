[seek-results.json](seek-results.json) is generated by:

```sh
IK_EVIDENCE=./evidence/issue-16/seek-results.json npm test --prefix platform
```

It records 20 public random seeks, final world target/endpoint diagnostics,
maximum repeated-seek matrix delta, maximum planted-foot residual, setup
nonmutation and result isolation. Tests require <=1e-5 matrix delta and <=0.5
logical-pixel residual. The generated JSON contains actual measurements.

Additional public tests check both bend directions at 9 phases; exact mix0 FK;
setup evaluation; JSON and portable ZIP roundtrip; v0→v1 geometry preservation;
malformed constraints and capability rejection; combined IK→mesh/region output;
singular/degenerate fallback; and explicit numerical failure. The real robot ZIP
manifest is evaluated at 24 poses, comparing region-v0 with v1 empty-IK output
exactly. This does not rerun or overwrite the historical Gate 1 media/performance
measurements.

Standalone tests cover off-axis endpoints, child reflection, affine ancestors,
root reflection, inner/outer unreachable annuli, ordering and final diagnostics.
An independent early review found a near-fold numerical cancellation at limb
lengths around 1e14. The factored cosine correction has a durable both-bend
regression; beyond floating-point pixel precision, the evaluator returns explicit
`INVALID_INPUT` rather than a false full-mix `solved` result. Disabled IK bypasses
unused inverse arithmetic.
