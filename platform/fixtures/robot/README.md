art-input.zip and commands.json. The ZIP contains original T01 PNGs and a root only:
no rig, attachments or animation. Import it through Editor's package chooser, then
invoke native-recipe.mjs with the Browser host's actual discovered tools handle.

three drafted hand oscillations to the brief's two.

editor Session, after the observed correction. Open it directly in `/player.html`;
no Spine data, editor state or filesystem source paths are used by the player.

`../source/robot-layout.json`; these are internal evaluation assets.
